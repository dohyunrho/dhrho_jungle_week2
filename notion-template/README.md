# 🌴 정글 학습 OS — Notion 가져오기 안내

이 묶음은 크래프톤 정글의 주차 운영, 스크럼, 코어타임, 코드 관리, GitHub Projects, WIL 규칙을 개인 학습 시스템으로 정리한 템플릿입니다.

## 가장 빠른 가져오기

1. Notion 데스크톱 또는 웹에서 `설정 → 가져오기 → ZIP`을 선택합니다.
2. 같은 폴더에 생성된 `jungle-learning-os-notion-import.zip`을 업로드합니다.
3. 가져온 데이터베이스와 페이지를 `🌴 정글 학습 OS` 페이지 아래로 이동합니다.

## 가져온 뒤 속성 확인

Notion은 파일의 표 데이터를 데이터베이스로 만들지만 관계형 속성과 데이터베이스 템플릿은 자동으로 연결하지 않습니다. 아래 속성만 한 번 설정합니다.

- `주차`: `주차별 목표` 데이터베이스와 Relation으로 변경
- `연결된 문제`: `문제 풀이·코드 로그`와 Relation으로 변경
- `GitHub 코드`, `GitHub Issue`, `커밋`, `블로그 URL`: URL 속성
- `처음 공부한 날`, `마지막 복습일`, `다음 복습일`, `학습일`, `작성일`, `게시일`: Date 속성
- `복습 필요`, `WIL 후보`, `10시 출근`, `정글 컴퍼스 등록`: Checkbox 속성
- `학습 상태`, `이해도`, `AI 도움 수준`, `단계`, `WIL 상태`: Select 속성

## 데이터베이스 템플릿 만들기

`templates` 폴더의 페이지 내용을 대응하는 데이터베이스의 새 템플릿 본문에 복사합니다.

- `주차_시작.md` → 주차별 목표
- `개념_노트.md` → 개념 노트
- `코드_로그.md` → 문제 풀이·코드 로그
- `데일리_로그.md` → 데일리 로그
- `WIL_회고.md` → WIL·회고

## 역할 분담

- GitHub Projects: 해야 할 일과 진행 상태
- 로컬 저장소: 직접 구현과 테스트
- GitHub 저장소: 코드와 매일의 커밋 이력
- Notion: 핵심 역량, 이해도, 문제 해결 과정, 복습, WIL

Notion에서 GitHub Projects의 칸반을 다시 만들지 않습니다.
