# 📜 학습 루틴과 그라운드 룰

## 1. 핵심 역량

- WEEK 2부터 매주 커리큘럼을 팀원들과 검토한다.
- 달성하고 싶은 핵심 역량을 세 가지로 구체화한다.
- 각 역량에는 완료 여부를 판단할 수 있는 기준을 적는다.

## 2. AI 사용 원칙

- 맨몸 코딩 기간에는 먼저 문제를 직접 이해하고 시도한다.
- AI를 사용한다면 Study Mode 또는 Guided Learning처럼 학습을 유도하는 방식을 우선한다.
- AI 사용 시점, 질문, 받은 도움, 직접 검증한 내용을 기록한다.
- 완성 코드를 받는 것보다 개념 질문, 힌트, 코드 리뷰 순서로 도움을 받는다.

## 3. 협업

- 매일 오전 스크럼에서 오늘 할 일을 공유한다.
- 오전 10시까지 교육장에 출근한다.
- 코어타임에는 서로 질문하고 설명하며 동료 학습을 진행한다.
- 진행 상황은 GitHub Projects에서 공유한다.
- 팀 프로젝트에서는 PR을 리뷰하고 병합 후 전체 기능을 다시 검증한다.
- 매주 마지막 코어타임에는 한 주를 회고한다.

## 4. 코드 관리

- 개인 학습 기간에는 개인 저장소에서 작업한다.
- 매일 의미 있는 커밋 이력을 남긴다.
- 팀 과제에서는 팀 저장소, Fork, 브랜치 전략과 PR 리뷰를 사용한다.
- 병합 후 실패가 발생하면 원인을 끝까지 확인한다.
- Pintos 저장소는 과정 중 Public, 수료 후 Private 전환 규칙을 지킨다.

## 5. 진척도 관리

- WEEK 2부터 GitHub Projects를 사용한다.
- 기본 상태는 `To Do → In Progress → Done`이다.
- 주초에 할 일을 등록하고 진행 중 자유롭게 조정한다.
- Notion에서는 동일한 칸반을 복제하지 않고 학습 증거와 복습을 관리한다.

## 6. WIL

- 매주 배운 내용을 개인 블로그에 정리한다.
- 학습 포인트, 문제 해결 과정, 개선 아이디어를 중심으로 작성한다.
- 게시한 블로그 URL을 정글 컴퍼스 포럼에 등록한다.
