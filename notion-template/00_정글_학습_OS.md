## 주간 흐름

1. 주초: 커리큘럼 검토 → 핵심 역량 3개 설정 → GitHub Task 등록
2. 매일 오전: 데일리 로그 → 오늘의 Issue 선택 → 스크럼 공유
3. 공부 중: 개념은 Notion, 구현은 저장소, 진행 상태는 GitHub Projects
4. 코어타임: 질문 1개와 공유할 지식 1개 준비
5. 학습 종료: 테스트 → 커밋 → 이해도 평가 → 복습 지정
6. 목요일: WIL 후보 모으기 → 회고 → 블로그 게시
